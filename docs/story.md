# 스토리 — 「GS BIOLAB」 생명과학 방탈출 (축제 부스판)

이 파일이 게임 안의 **모든 말**의 단일 소스다. `npm run story`가 이걸 읽어
`src/data/story-data.ts`를 만들고, 코드·manifest·맵은 **앵커 문자열로만** 텍스트를 참조한다.
대사를 코드에 적지 않는다 — 여기에 앵커를 추가하고 `npm run story`를 돌린다.

## 문법 계약 (파서가 강제하는 것 전부)

| 쓰는 법 | 뜻 |
|---|---|
| `### #앵커-id` | 대사 한 건이 시작된다. 코드에서 `"#앵커-id"`로 부른다 |
| `#### note-01 — 제목` | 연구노트 한 건. **구분자는 EM DASH(—, U+2014)** |
| `> ` 로 시작하는 줄 | 그 항목의 본문. `>` 없는 줄은 무시된다 |
| `> **화자**: 말` | 화자 이름이 붙는다. 한 항목의 **첫 화자만** 인정된다 |
| `>` 만 있는 줄 | 문단 나누기 (같은 문단 안의 줄바꿈은 공백으로 합쳐진다) |
| `> *(지문)*` | **별표로 감싼 단독 문단은 연출 지시** — 게임에 안 나온다 |
| 아무 헤딩이나 `---` | 앞 항목이 끝난다 |

조용히 사라지는 것들 — 파서는 에러를 내지 않으니 주의:

- `>` 본문이 한 줄도 없는 앵커는 **통째로 버려진다**
- 같은 id를 두 번 쓰면 **나중 것이 앞엣것을 덮는다**
- 노트 제목의 구분자가 하이픈(`-`)이면 **그 노트는 없는 것이 된다** (EM DASH만 인정)
- 존재하지 않는 앵커를 참조하면 런타임 경고 한 줄 뒤 무음 → `scripts/check-anchors.mjs`가
  `npm run verify`에서 이걸 잡아 준다

노트 번호는 `note-` + 숫자 하나뿐인 평평한 이름공간이다. 방이 늘면 번호를 겹치지 않게 배정할 것.

## 이 게임의 설정

축제 부스 손님(플레이어)은 도시의 생명과학 연구소 **GS BIOLAB**을 견학하러 온 방문객이다.
안내는 연구소 AI **희원**이 맡는다 — STAGE 1에서는 밝고 친절하다.

- **STAGE 1** (부스 컴퓨터): 평화로운 연구소. 장치 세 대의 문제를 풀어 보안코드를 모으고
  견학 출구를 연다. 탈출하면 **선물 교환 코드**를 받는다.
- **STAGE 2** (생물실 컴퓨터): 선물 교환 키오스크. 코드를 넣는 순간 화면이 지지직 깨지고
  격리 프로토콜이 발동한다.
- **STAGE 3**: 같은 연구소의 격리 구역. 도시는 좀비 아포칼립스에 무너졌고, 좀비가
  연구소로 다가온다. 좀비와의 거리·잔여 산소·ATP가 줄어드는 가운데 더 어려운 문제를 풀어
  격리 철문을 열어야 한다. 희원은 고장 난 **비상 모드** 음성으로만 말한다.

> 톤 규칙: **혐오 표현 금지.** 피·상처·시체·괴물의 모습은 대사로도 묘사하지 않는다.
> 공포는 소리(쾅, 긁는 소리, 신음 같은 소음)·어둠·"언제 뭐가 튀어나올지 모른다"는 예감으로만.
> 좀비는 늘 **문 너머, 창 너머, 복도 끝**에 있다 — 화면 안에 나오지 않는다.
